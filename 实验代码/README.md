# 多标签测试时自适应：教师-学生一致性 + 条件分布匹配 + 协方差结构匹配

针对多标签 TTA 的三个核心问题（低熵预测对错不可辨、类间关系缺失、类别分布不平衡），
按"多模型预测一致性"思路实现的完整框架，并已对接 `E:\mttta` 项目的
ViT-B/16(ASL) / ResNet50 VOC 模型与 VOC-C 损坏测试集。

## 一、方案分析（针对三大核心问题）

### 问题 1：低熵无法区分对错 → 教师-学生一致性
单个样本用二元熵优化，熵小只说明"自信"，不说明"正确"。引入教师/学生双网络：
教师接收弱增强（测试变换）视图、学生接收强增强视图，二者同源初始化（同一
checkpoint），教师参数由 EMA 累积学生更新。梯度只作用于学生。当两个网络对同一
样本的预测不一致时才产生有效学习信号——这就是"用扩充样本后的多模型预测一致性
来确认低熵预测是否可信"的实现。

### 问题 2：类间关系无法建模 → 两个结构化正则
逐类 BCE 的坍缩倾向（所有类被推向 0 或 1）由两项约束纠正：

- **条件分布匹配 L_cond**：只用"与类原型 C_c 余弦相似度 > τ 的样本子集"对齐
  学生预测均值与在线频率 π^c，无该类语义的样本不参与正则，避免"无关样本被迫
  抬高该类概率"。
- **协方差结构匹配 L_struct**：学生批协方差 Σ^s 对齐教师预测的在线 EMA 协方差
  Σ^t（以源域协方差初始化），保持类间共现结构自洽且随测试流演化。

### 问题 3：分布不平衡 → 三个机制
- **动态频率 π^c(t)**：教师预测批均值的 EMA，摆脱源域先验固化；
- **自适应类权重 w_c = (1 - p̄_t^c)^γ**：高频类梯度被抑制；
- **双阈值过滤 + 在线 focal（可选）**：只在教师高置信区学习，不确定区不产生梯度；
  focal 系数可放大长尾类的犹豫样本梯度。

**5 种损坏主实验（方案默认参数）**：

|---|---|---|---|
| gaussian_noise | 78.501 | 78.427 | -0.07 |

**诊断**（对应方案三大机制在强模型上的失配）：
- L_cons 正掩码覆盖率仅 ~5%、负掩码 ~89%：ASL(γ⁻=4, clip=0.05) 训练出的概率极度稀疏，
  固定阈值 τ_pos=0.8 筛不出正伪标签，正则与一致性损失全部退化为"整体下压"；
- π^c 被教师批均值拉低（漂移 0.05-0.07），L_cond 同向负偏；
- EMA m=0.999 在 78 批的单遍流上教师几乎不动（92.5% 仍为初始权重），框架退化为源模型自蒸馏；
- 源模型训练（train_voc_asl.py）**无任何数据增强**，强增强视图对学生是双重分布偏移。

**gaussian_noise 消融**（定位每个修正的贡献）：

## 六点五、组件深化实验（2026-09-03）

### L_struct 激活：相关矩阵形式（实验①）

原始 Frobenius 对齐协方差**尺度**，在 ASL 稀疏概率下量级 ~1e-6 形同虚设；改为
**相关矩阵对齐**（`--struct_form corr`，尺度无关，直接对应方案原文"类别共现关系
保持一致"）后损失激活到 ~0.17，gaussian/glass_blur 上微正（+0.005/+0.044）。
结论：采纳 `--struct_form corr --lambda_struct 0.25`；无偏移场景下其空间有限，
先验偏移（下节）才是其设计主场。

## 六、与方案 A（自限熵平衡）的关系

方案 A 的结论对本框架有三点直接借鉴：

1. **方向必须来自模型自身**——本框架的 L_cons 用双阈值教师伪标签提供方向。
   在强模型（ASL ViT，零样本 ~78）下教师高置信预测更可靠，该假设成立；
   在弱模型（resnet50，零样本 ~28）下教师欠自信，τ_pos=0.8 的正掩码覆盖率
   仅 ~5%，L_cons 退化为负样本主导——这正是实验中观察到的现象，需要降低
   τ_pos 或引入预热。
2. **类级频率权重在强模型下可能是偏差源**——方案 A 的报告指出 IA-SAER 的
   类级 α 在强模型下退化。本框架的 w_c 同为类级权重，因此 `--gamma_w 0`
   可一键关闭做消融。
3. **KL 边际只做刹车**——本框架的 L_cond 起类似的边际约束作用，但其对齐
   目标 π^c 是在线估计而非固定先验，且只在原型相关子集上生效。
